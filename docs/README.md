# Project Docs

This folder contains planning, design, and historical architecture notes for PiDashboard.

The active application lives at the repository root (`admin/`, `core/`, `widgets/`, etc. — no nested workspace folder). Older documents may mention a top-level `core/`, `core_legacy_archive/`, `src-anything/`, or a `LiteDashboard/` wrapper folder; those paths are historical and no longer reflect the current layout.

For current setup and development entry points, start with the repository root `README.md`.
